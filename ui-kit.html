Internal Reference — Not Linked From Nav

Design system reference for the E4LA site.

This page catalogs the canonical visual system defined in style.css — the one CLAUDE.md protects as "the existing visual identity": dark #07060D base, Manrope typography, gold/purple neon CTAs. Every example below renders with the real stylesheet, not a re-creation, so it stays accurate as the site evolves.

Scope note: about.html, and the auth/portal pages (sign-in, sign-up, forgot-password, verify-email, portal) currently run on two different token sets (assets/css/about.css, auth.css + portal.css) and Portal loads Inter instead of Manrope. This kit documents the canonical system only — see "Design drift found" below for details. Nothing in those files was changed to build this page.

Behavior

Motion & Interaction Principles

All interaction logic lives in script.js (plain script, not a module). motion.js is reserved for Motion-for-JS-driven work and today only targets .auth-page. Every pattern below respects prefers-reduced-motion.

  • Scroll reveal — any [data-r] element (optionally staggered with data-d="n") fades/slides in once via IntersectionObserver, adding an .in class.
  • Service card drift — idle .svc-card elements auto-drift with a per-card sine-wave "personality"; hover/focus freezes the card flat. Desktop + fine-pointer only.
  • CTA neon beam — .cta-neon buttons get a live-measured circular badge and a repeating SVG gradient beam (3 animated peaks via SMIL) recomputed on load/resize.
  • Timeline auto-cycle — .tstep and coaching timeline steps advance on a timer, pausing on hidden tabs and reduced motion.
  • Pinned scroll (services.html only) — .svcd-pin manually toggles fixed/absolute/flow positioning (not position:sticky, which breaks under this site's global overflow-x:hidden). Gated to min-width:640px + pointer:fine; falls back to a plain stacked list otherwise.
  • Hero word scramble — #js-word cycles a word list with a scramble/decode effect every 2s.

Design Drift Found

While building this kit, three separate token sets turned up across the site. Documented here for visibility — none of these files were changed.

Home / Services (canonical)

Manrope. Gold/purple neon CTAs. This is the system documented above.

style.css

About page

Manrope + Instrument Serif. Violet/pink/orange gradient system, own --bg/--panel tokens. Does not load style.css.

assets/css/about.css

Auth & Portal

Orange→pink→purple gradient system. Portal loads Inter, not Manrope — the only page on the site that does.

auth.css, portal.css
Recommendation (not actioned): when about/auth/portal are next touched, consider migrating them onto the canonical style.css token set — starting with Portal's font (Inter → Manrope) since that's the most visible brand inconsistency, a user could notice it in a single session.

Working Agreement

Usage Guidelines

From this project's CLAUDE.md — restated here so this reference is self-contained.

  • Vanilla HTML/CSS/JS only. No React, Tailwind, or shadcn — not even for one component.
  • Reuse existing classes (svc-card, cta-neon, tstep, grad-text, section-heading, data-r/data-d) instead of inventing new ones.
  • When adding classes to an element, keep every class already on it.
  • script.js stays plain (non-module) and holds core interaction logic; motion.js is the only place for Motion-for-JS work, loaded as a module.
  • Edit style.css section by section — it's an additive/override history of dated passes; add new scoped blocks rather than restructuring old ones.
  • Don't redesign or make visible UI changes without explicit approval first.
